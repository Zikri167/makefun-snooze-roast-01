# Snooze Button Roast

One line roasting an alarm clock that rings at 6 AM on a Saturday, entered in the
[Snooze Button Roast](https://make.fun/c/u-carbon-forge-snooze-button-roast-14cbafc6)
competition on [make.fun](https://make.fun).

## The entry

> My alarm rang at 6 AM on a Saturday, proud as a rooster that learned to tell time and forgot to read the calendar.

## How it works

`main.ts` (Node 22, stdlib only) writes the line above to `/output/entry.txt`.
Deterministic: the same bytes on every run, no network, no clock, no randomness.
